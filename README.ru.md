# IT-STE

[English](README.md)

**IT-STE (IT Simplified Technical English)** — открытый проект контролируемого технического английского для IT-документации. Он развивает принципы ASD-STE100 с учётом программного обеспечения, инфраструктуры, API, безопасности и эксплуатации IT-систем.

Цель — сделать инструкции и описания однозначными, последовательными и удобными для людей, переводчиков и LLM. Проект объединяет собственный стандарт IT-STE, переводы и версионируемый корпус материалов об ASD-STE100 с сохранением происхождения и прав на каждый материал.

Это независимый проект, а не официальный стандарт или перевод ASD. Доступность исходного стандарта не означает разрешение на его перепубликацию или перевод.

## Языковая политика

**Английский (`en`) — основной и нормативный язык.** Документация проекта без языкового суффикса и исходные нормативные записи IT-STE пишутся по-английски.

**Русский (`ru`) — предпочтительный второй язык.** Русские переводы приветствуются, но не обязательны и могут появляться позже соответствующих английских материалов. Остальные языки опциональны и обозначаются тегами BCP 47. При расхождении перевода с английским текстом IT-STE действует английский текст.

См. [языковую политику](docs/language-policy.ru.md) и её [английский оригинал](docs/language-policy.md).

## Что храним

- **ASD-STE100:** отдельные версии исходного стандарта, сведения об источниках и, при наличии необходимых прав, структурированные правила, термины и переводы.
- **IT-STE:** собственные версии правил и словаря для IT, примеры и связи с источниками адаптации.
- **Переводы:** отдельные языковые записи, закреплённые за точной версией и контрольной суммой оригинала.
- **LLM-корпус:** производные JSONL-выгрузки с идентификаторами, версиями, языком, происхождением и лицензией каждой записи.

## Структура

```text
catalog.json                       # Реестр стандартов и опубликованных снимков
standards/
  asd-ste100/versions/              # Версии ASD-STE100: не смешиваются с IT-STE
  it-ste/
    domains/                       # Версионируемые черновые ID IT-доменов
    adaptation-plans/              # Редакторские решения, закреплённые за источником
    versions/                      # Версии собственного стандарта
      <version>/revisions/<revision>/
        manifest.json              # Состав конкретного снимка
        sources/                   # Метаданные источников и сведения о правах
        content/<language>/
          rules/<id>.json          # Одна запись — одно правило
          terms/<id>.json          # Одна запись — один смысл термина
        relations.jsonl            # Связи адаптации и замены между записями
templates/                         # Образцы записей; не часть стандарта
llm/                               # Контракт LLM-выгрузок
docs/storage.md                    # Правила хранения и версионирования
exports/                           # Генерируемые JSONL; не хранятся в Git
```

Для обоих стандартов действует одинаковая структура снимка. **Версия стандарта** и **ревизия корпуса** — разные сущности: перевод или метаданные можно обновить без выдуманной новой редакции ASD-STE100. JSON-записи — единственный канонический источник; Markdown-представления и LLM-выгрузки должны строиться из них.

Подробности: [хранение и версии](docs/storage.ru.md), [процесс адаптации](docs/it-ste-adaptation.ru.md), [LLM-формат](llm/README.ru.md), [шаблоны](templates/).

## Статус

Правила и словари IT-STE ещё не опубликованы, реестр версий пуст. Первый черновой реестр доменов и закреплённый за источником план адаптации охватывают все 53 правила и 8 рекомендаций Issue 9. Разделы 1–3 рассмотрены: 23 исходных правила сопоставлены девяти планируемым ID правил IT-STE; остальные 38 исходных блоков явно остаются непроверенными. Для Issue 9 добавлены отслеживаемые метаданные источника и разрешённая к публикации, механически извлечённая [производная поисковая база](docs/asd-ste100-local-reference.ru.md). Исходный PDF не отслеживается Git и не публикуется. Экспортёр и автоматические проверки канонического корпуса пока не реализованы.
