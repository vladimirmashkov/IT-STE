# Процесс адаптации IT-STE

[English](it-ste-adaptation.md)

Основным является английский документ. План адаптации преобразует закреплённую ревизию источника ASD-STE100 в проверенные редакторские решения до создания нормативных записей IT-STE.

## Текущий план

Первый план закреплён за ASD-STE100 Issue 9, ревизия представления `r0001`:

```text
standards/it-ste/
  domains/v1.0.0.json
  adaptation-plans/asd-ste100/issue-9/r0001/
    manifest.json
    map.jsonl
```

`domains/v1.0.0.json` определяет стабильные черновые идентификаторы IT-контекстов. В `map.jsonl` есть одна запись для каждого из 53 правил и 8 общих рекомендаций источника. Манифест плана аутентифицирует исходную базу, реестр доменов и карту по SHA-256.

План не является релизом IT-STE, предварительные домены на основе заголовков не нормативны, а целевой ID правила не назначается до редакторского решения о необходимости правила.

## Состояния оценки

Каждый исходный блок проходит независимые состояния:

- `assessment.status`: `unreviewed`, `in-review` или `reviewed`;
- `assessment.applicability`: `pending`, `adopt`, `adapt`, `split`, `merge` или `not-applicable`;
- `assessment.adaptation_action`: `pending`, `create-rule`, `create-rules`, `merge-into-rule` или `record-rationale-only`.

Для `reviewed` обязательно непустое английское поле `rationale` и одно согласованное решение:

| Применимость | Действие | Целевые ID |
| --- | --- | --- |
| `adopt` или `adapt` | `create-rule` | ровно один |
| `split` | `create-rules` | два или больше |
| `merge` | `merge-into-rule` | ровно один; его могут совместно использовать только другие решения merge |
| `not-applicable` | `record-rationale-only` | отсутствуют |

Предварительные домены используют ID из закреплённого реестра `standards/it-ste/domains/v1.0.0.json`. Целевые ID имеют точный вид `ITSTE-R-NNNN` и обозначают собственные правила IT-STE, а не правила ASD.

## Проверка одного исходного блока

1. Аутентифицируйте источник и план:

   ```sh
   python3 tools/asd_ste100_local.py doctor
   python3 tools/it_ste_adaptation.py check
   ```

2. Прочитайте компактную карточку источника. Для конкретного вопроса используйте ограниченный фрагмент, а `--full` — только если контекста всё ещё недостаточно:

   ```sh
   python3 tools/asd_ste100_local.py rule 5.2
   python3 tools/asd_ste100_local.py excerpt 5.2 "one instruction"
   python3 tools/asd_ste100_local.py rule 5.2 --full
   ```

3. Изменяйте только запись этого блока в карте. Объясните, что применимо к IT, что требуется изменить и почему. По умолчанию не копируйте формулировку источника в правило IT-STE.
4. Назначайте целевые ID только после решения создать, разделить или объединить правила.
5. Обновите хеши и количества, затем проверьте план:

   ```sh
   python3 tools/it_ste_adaptation.py seal
   python3 tools/it_ste_adaptation.py check
   ```

Команда `init` создаёт план, только когда ни одного файла плана ещё нет, и никогда не перезаписывает ручную работу. После изменений карты используйте `seal`. Если изменились байты закреплённого реестра доменов, `seal` остановится до проверки классификации; только после неё используйте `seal --accept-domain-change`, чтобы явно зафиксировать миграцию.

## От плана к стандарту

Рассмотренные решения карты служат входными данными, но не заменяют канонические записи IT-STE. Английские правила создаются в версионируемом снимке `standards/it-ste/versions/<version>/revisions/<revision>/content/en/`. Сохраняйте точные координаты источника и обоснование, считайте русский перевод опциональным и подчинённым английскому, а представления для людей и LLM создавайте из канонических записей.

Текущий профиль инструмента намеренно закреплён за Issue 9 `r0001`. Для будущей редакции источника или исправленного представления создаётся отдельный неизменяемый путь плана и доверенный профиль источника; этот план нельзя перепривязывать к другому источнику.

Проект является независимой работой, а не официальной рекомендацией ASD. Сохраняйте сведения о правах ASD для производного содержимого и обязательную ссылку IT-STE: https://github.com/vladimirmashkov/IT-STE.
