# Производный справочник ASD-STE100 Issue 9

[English](asd-ste100-local-reference.md)

Репозиторий содержит разрешённый машиночитаемый производный файл ASD-STE100 Issue 9 для экономного поиска агентами. Исходный PDF не публикуется. Он остаётся только в `.local/`, когда сопровождающему проекта нужна воспроизводимая пересборка базы.

Нормативным источником остаётся PDF, полученный от ASD. Опубликованная база создана механически и не прошла содержательную проверку. Столбцы таблиц, типографика, диаграммы и переносы могут быть распознаны неверно. Когда важна точная формулировка или классификация, проверяйте указанную физическую страницу PDF.

## Опубликованные артефакты

```text
standards/asd-ste100/versions/issue-9/revisions/r0001/reference/
  reference.sqlite3  # Страницы, правила, рекомендации, словарь и FTS
  manifest.json      # Хеши, количества, генератор и состояние прав
  NOTICE.md          # Владелец, разрешение, атрибуция и статус проверки
```

Каталог `reference/` — версионируемый и отслеживаемый Git артефакт публикации. Сохраняйте его вместе с ревизией, не считайте временным результатом сборки и не добавляйте в правила игнорирования.

Индекс содержит:

- все 434 физические страницы как резервный текст с сохранением раскладки;
- 53 адресуемых правила Part 1;
- 8 адресуемых общих рекомендаций (`GR-1` — `GR-8`);
- 2 196 строк словаря, разделённых на четыре подписанных столбца;
- полнотекстовые индексы SQLite для компактного поиска.

Эмбеддинги и внешние API не нужны. Точный лексический и структурный поиск детерминирован и не требует загружать весь стандарт в контекст.

## Проверка и поиск

Опубликованный производный файл работает без исходного PDF и Poppler:

```sh
python3 tools/asd_ste100_local.py doctor
python3 tools/asd_ste100_local.py overview
```

`doctor` сверяет SHA-256 базы с манифестом, целостность SQLite и внешние ключи, метаданные, количество записей и FTS-строк, точные наборы ID правил и рекомендаций, флаги публикации и SHA-256 notice и записи о разрешении. Если локальный PDF доступен, дополнительно проверяются его SHA-256 и инструменты Poppler.

Раскрывайте контекст постепенно:

```sh
# Найти только подходящие заголовки или фрагменты.
python3 tools/asd_ste100_local.py rules --section 5
python3 tools/asd_ste100_local.py search "passive voice" --scope rules

# Сначала карточка правила; полный текст — только при необходимости.
python3 tools/asd_ste100_local.py rule 5.1
python3 tools/asd_ste100_local.py rule 5.1 --full

# Сначала значение и альтернативы; примеры — только при необходимости.
python3 tools/asd_ste100_local.py word test
python3 tools/asd_ste100_local.py word test --pos n --full

# Страница — только резервная проверка.
python3 tools/asd_ste100_local.py page 87
```

Все команды поиска поддерживают `--json`. Для `search` доступны области `rules`, `dictionary`, `pages` и `all`. Диапазон `--limit` — 1–20, ограничение действует на суммарный результат. Полный JSON не дублирует общий текст и его постраничные или поколоночные части.

## Воспроизводимая пересборка и публикация

Сопровождающему проекта нужны:

- `.local/sources/ASD-STE100-issue-9.pdf`;
- Python 3.11 или новее;
- команды Poppler `pdftotext` и `pdfinfo`;
- SHA-256 источника `d1f4ea9e7cd6e46b47aa9057209f99e78c0e9cfc4e27a5b07895b05c1a166431`.

Запускайте из корня репозитория:

```sh
python3 tools/asd_ste100_local.py build --force
python3 tools/asd_ste100_local.py publish --force
python3 tools/asd_ste100_local.py doctor
python3 -m unittest tests/test_asd_ste100_local.py
```

`build` записывает промежуточные артефакты только в `.local/`. `publish` аутентифицирует их и копирует только производную базу и манифест в фиксированный версионируемый каталог. PDF никогда не копируется. Входные и выходные пути не могут совпадать, а произвольные публичные пути вывода отклоняются.

## Правила надёжности

- Считайте строки словаря в верхнем и нижнем регистре разными кандидатами. Не объединяйте их регистронезависимо.
- Поиск слова без `--full` намеренно не показывает примеры, но сохраняет столбец значения и альтернатив.
- Поиск правила без `--full` возвращает точный заголовок, ссылки на страницы и размер подробностей, а не сгенерированный пересказ.
- `wrapped-headword` — предупреждение о структуре. Сохраняйте показанное написание и проверяйте страницу до исправления дефиса на переносе.
- Если запрос отсутствует или неоднозначен, используйте `search`, затем одну указанную `page`. Не читайте все страницы.
- Указывайте ASD-STE100 Issue 9 и физическую страницу PDF. Если доступна печатная метка страницы, инструмент также её показывает.
- Не представляйте механическое извлечение, ответ LLM или адаптацию IT-STE как официальную рекомендацию ASD.

## Граница прав

Владелец репозитория фиксирует полученное вне сети письменное разрешение публиковать производные файлы Issue 9, включая эту машиночитаемую базу. Публикация исходного PDF явно исключена. См. [запись о разрешении](permissions/asd-ste100-issue-9-derivatives.ru.md) и `NOTICE.md` артефакта.

Разрешение не устанавливает более широкую лицензию для последующих пользователей и не переводит материалы ASD под лицензии проекта IT-STE. Сохраняйте сведения о правах ASD, notice производного файла и обязательную ссылку на IT-STE. Никогда не добавляйте исходный PDF в Git.
