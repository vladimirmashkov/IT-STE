# Локальный справочник ASD-STE100 Issue 9

[English](asd-ste100-local-reference.md)

Этот процесс преобразует законно полученную локальную копию ASD-STE100 Issue 9 в **закрытый поисковый индекс** для агентов. PDF, извлечённый текст, база SQLite и сгенерированный манифест остаются в `.local/`, который игнорируется Git. Они не являются корпусом, разрешённым к публикации.

Нормативным источником остаётся PDF. Извлечение выполнено механически и не прошло содержательную проверку. Столбцы таблиц, типографика, диаграммы и переносы могут быть распознаны неверно. Когда важна точная формулировка или классификация, проверяйте указанную физическую страницу PDF.

## Требования

- `.local/sources/ASD-STE100-issue-9.pdf`
- Python 3.11 или новее
- команды Poppler `pdftotext` и `pdfinfo`
- SHA-256 проверенного источника: `d1f4ea9e7cd6e46b47aa9057209f99e78c0e9cfc4e27a5b07895b05c1a166431`

Сборщик отклоняет PDF с другим хешем. Это предотвращает незаметное смешивание редакций и изменённых файлов.

## Сборка и проверка

Запускайте из корня репозитория:

```sh
python3 tools/asd_ste100_local.py build
python3 tools/asd_ste100_local.py doctor
python3 -m unittest tests/test_asd_ste100_local.py
```

Используйте `build --force` только для замены существующей базы после изменения сборщика. Результат — `.local/derived/asd-ste100/issue-9/reference.sqlite3` и соседний `manifest.json`. CLI отклоняет пути источника, базы и манифеста, которые после разрешения находятся вне `.local/`, а также совпадающие пути входа и выхода.

Индекс содержит:

- все 434 физические страницы как резервный текст с сохранением раскладки;
- 53 адресуемых правила Part 1;
- 8 адресуемых общих рекомендаций (`GR-1` — `GR-8`);
- 2 196 строк словаря, разделённых на четыре подписанных столбца;
- полнотекстовые индексы SQLite для компактного поиска.

Эмбеддинги и внешние API не нужны. Точный лексический и структурный поиск дешевле, детерминирован и достаточен для идентификаторов и контролируемого словаря стандарта.

## Экономный по токенам процесс для агента

Раскрывайте контекст постепенно. Не помещайте полное извлечение PDF в контекст агента.

```sh
# 1. Проверить точный источник и индекс.
python3 tools/asd_ste100_local.py doctor

# 2. Прочитать короткую сводку индекса.
python3 tools/asd_ste100_local.py overview

# 3. Найти только заголовки подходящих правил.
python3 tools/asd_ste100_local.py rules --section 5
python3 tools/asd_ste100_local.py search "passive voice" --scope rules

# 4. Сначала прочитать карточку; полный текст — только при необходимости.
python3 tools/asd_ste100_local.py rule 5.1
python3 tools/asd_ste100_local.py rule 5.1 --full

# 5. Сначала прочитать значение и альтернативы; примеры — при необходимости.
python3 tools/asd_ste100_local.py word test
python3 tools/asd_ste100_local.py word test --pos n --full

# 6. Вывод страницы использовать только для проверки.
python3 tools/asd_ste100_local.py page 87
```

Все команды поиска поддерживают `--json`. Для `search` доступны области `rules`, `dictionary`, `pages` и `all`. Начинайте с самой узкой области и небольшого `--limit`; допустимый диапазон — 1–20, а ограничение действует на суммарный результат всех областей. Полный JSON не дублирует общий текст и его постраничные или поколоночные части.

## Правила надёжности

- Считайте строки словаря в верхнем и нижнем регистре разными кандидатами. Не объединяйте их регистронезависимо.
- Поиск слова без `--full` намеренно не показывает примеры, но сохраняет столбец значения и альтернатив.
- Поиск правила без `--full` возвращает точный заголовок, ссылки на страницы и размер подробностей, а не сгенерированный смысловой пересказ.
- `wrapped-headword` — предупреждение о структуре. Сохраняйте показанное написание и проверяйте страницу до исправления дефиса на переносе.
- Если запрос отсутствует или неоднозначен, используйте `search`, затем одну указанную `page`. Не читайте все страницы.
- В ссылке указывайте ASD-STE100 Issue 9 и физическую страницу PDF. Если доступна печатная метка страницы, инструмент также её показывает.
- Не представляйте механическое извлечение, ответ LLM или адаптацию IT-STE как официальную рекомендацию ASD.

## Граница прав

В PDF указано «All rights reserved», а воспроизведение и публикация ограничены с учётом перечисленных специальных прав использования. Бесплатное получение копии не подтверждает право публиковать её или извлечённый текст. Поэтому в Git хранятся только сборщик, метаданные источника и инструкции. Не добавляйте `.local/` в индекс, не копируйте извлечённый текст в отслеживаемые фикстуры и не публикуйте базу без документированного разрешения.
