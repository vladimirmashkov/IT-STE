# Последовательный разбор словаря IT-STE

[Authoritative English document](it-ste-vocabulary.md)

Это опциональное русское резюме. Основной язык — английский. Здесь описана редакторская очередь, а не утверждённый словарь или релиз стандарта.

## Что сделано

Партия `standards/it-ste/vocabulary-reviews/asd-ste100/issue-9/r0001/batch-001.json` содержит первые **40 строк** словаря ASD-STE100 Issue 9: от `D-P149-001` (A) до `D-P154-006` (acrid), физические страницы PDF 149–154. Порядок — страница, затем номер строки; неоднозначные и неприменимые строки не пропускались.

Для каждой строки предложены IT-значение, область применения, rationale, контекстные альтернативы и собственные положительный/проблемный примеры с пояснениями.

- `allowed`: 1;
- `restricted`: 20;
- `prohibited`: 9;
- `not-applicable`: 4;
- `needs-review`: 6.

**Все решения остаются `draft` / `editorial-review-needed`. Ни одно не утверждено.** Статус относится к указанному значению и контексту, а не ко всем употреблениям слова. Канонические ID терминов не назначены. Из 2 196 строк **2 156 ещё не рассмотрены**; следующая — **`D-P154-007`**.

Исходный признак одобрения — механический сигнал регистра букв, а не готовое IT-разрешение. Его нельзя автоматически наследовать. Для шести неоднозначных строк зафиксированы проблемы извлечения; визуальная проверка источника ещё требуется. Определения и примеры ASD в партию не копируются.

## Работа

```sh
python3 tools/asd_ste100_local.py doctor
python3 tools/it_ste_vocabulary.py check --compact-json
python3 tools/it_ste_vocabulary.py entry D-P149-001 --compact-json
```

Проверка сверяет источник и хэши, точный состав первых 40 строк, координаты, исходные статусы и предупреждения, порядок, количества, домены и границу чернового рассмотрения. Она не подтверждает правильность смысла или разметки PDF и не утверждает словарь. Текущий валидатор намеренно рассчитан только на партию 001; для следующих партий нужно расширить проверки, не пропуская строки и не объявляя их проверенными заранее.

Продолжать нужно с `D-P154-007`, читая ограниченные выборки и точные записи. Нельзя загружать весь словарь в контекст агента или автоматически превращать черновые решения в утверждённые записи.

```sh
python3 tools/it_ste_document.py build

```

Это производный файл: редактируйте JSON-источники и пересобирайте его. Проверка актуальности ничего не записывает. Черновик не является завершённым стандартом или готовыми данными для SFT. Агентам для экономии токенов доступны отдельные JSON-записи и точечная словарная команда.
