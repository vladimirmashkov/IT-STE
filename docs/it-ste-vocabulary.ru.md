# Последовательный разбор словаря IT-STE

[Authoritative English document](it-ste-vocabulary.md)

Это опциональное русское резюме. Основной язык — английский. Здесь описана редакторская очередь, а не утверждённый словарь или релиз стандарта.

Для продолжения в независимом треде начните с [основного handoff](it-ste-draft-handoff.md) или [русского резюме](it-ste-draft-handoff.ru.md): там есть история выполненной работы, ограниченная выборка текущих блокеров и разделение оставшихся задач. Полный сгенерированный черновик для старта читать не нужно.

## Что сделано

Все **2 196 исходных строк** словаря ASD-STE100 Issue 9, представление `r0001`, охвачены черновыми предложениями в **55 партиях**: `batch-001.json`–`batch-055.json` в каталоге `standards/it-ste/vocabulary-reviews/asd-ste100/issue-9/r0001/`. Порядок — физическая страница PDF, затем номер строки: от `D-P149-001` до последней строки `D-P433-007` (zero). Необработанных исходных строк не осталось; неоднозначные и неприменимые строки не пропускались.

Для каждой строки предложены IT-значение, область применения, rationale, контекстные альтернативы и собственные положительный/проблемный примеры с пояснениями.

- `allowed`: 90;
- `restricted`: 1 359;
- `prohibited`: 402;
- `not-applicable`: 146;
- `needs-review`: 199.

Всего: 2 196 черновых решений; необработанных исходных строк: 0.

**Все 2 196 решений остаются `draft` / `editorial-review-needed`. Ни одно не утверждено.** Статус относится к указанному значению и контексту, а не ко всем употреблениям слова. Канонические ID `ITSTE-T-*` не назначены; контекстные альтернативы не являются утверждёнными терминами.

**Полное черновое покрытие исходных строк не означает полного утверждённого IT-словаря.** Для терминов, специфичных только для IT, ещё нужна отдельная инвентаризация и редакторские решения по значениям. Утверждённого словаря и канонического набора терминов нет; готовность к релизу или SFT не заявляется.

Исходный признак одобрения — механический сигнал регистра букв, а не готовое IT-разрешение. Его нельзя автоматически наследовать. Шесть первоначальных неоднозначных случаев партии 001 разрешены после визуальной проверки физических страниц PDF 153–154. Ещё три блокера партии 002 разрешены после визуальной проверки страниц 156–157. Остальные строки в этой работе визуально не проверялись: **199 строк всё ещё требуют проверки значения или разметки**. Наличие черновика не подтверждает правильность значения или извлечённой структуры. Определения и примеры ASD в партии не копируются; IT-определения и примеры — собственная редакторская работа.

## Работа

```sh
python3 tools/asd_ste100_local.py doctor
python3 tools/it_ste_vocabulary.py check --compact-json
python3 tools/it_ste_vocabulary.py entry D-P433-007 --compact-json
python3 tools/it_ste_vocabulary.py check --batch standards/it-ste/vocabulary-reviews/asd-ste100/issue-9/r0001/batch-001.json --compact-json
python3 tools/it_ste_vocabulary.py entry D-P149-001 --batch standards/it-ste/vocabulary-reviews/asd-ste100/issue-9/r0001/batch-001.json --compact-json
```

По умолчанию `check` проверяет все партии, а `entry` ищет во всех партиях; `--batch standards/it-ste/vocabulary-reviews/asd-ste100/issue-9/r0001/batch-001.json` выбирает одну партию. Проверка сверяет источник и хэши, разрешение, реестр доменов, состав строк, координаты, исходные статусы и предупреждения, порядок, количества, обязательные редакторские поля и разделение прав. Она работает без закрытого PDF, не подтверждает правильность смысла или разметки PDF и не утверждает словарь.

Следующей необработанной исходной строки нет. Дальнейшая работа — 199 нерешённых случаев значения или разметки, дополнительные визуальные проверки и инвентаризация IT-терминов, отсутствующих в источнике. Читайте ограниченные выборки и точные записи. Нельзя загружать весь словарь в контекст агента или автоматически превращать черновые решения в утверждённый словарь либо обучающий корпус.

## Единый документ

[IT-STE-draft.md](IT-STE-draft.md) генерируется из всех 31 канонического draft-правила и всех 55 словарных партий:

```sh
python3 tools/it_ste_document.py build
python3 tools/it_ste_document.py check
```

Это производный файл: редактируйте JSON-источники и пересобирайте его. Проверка актуальности ничего не записывает. Черновик не является завершённым стандартом или готовыми данными для SFT. Агентам для экономии токенов доступны отдельные JSON-записи и точечная словарная команда.
