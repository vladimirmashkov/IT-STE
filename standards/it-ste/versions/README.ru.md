# Версии IT-STE

[English](README.md)

Здесь создаются каталоги `<version>/revisions/<revision>/` по [общей структуре](../../../docs/storage.ru.md). Опубликованных версий и нормативных записей пока нет.

Для `version` используется SemVer:

- **MAJOR** — несовместимое изменение нормативных требований или смысла разрешённых терминов.
- **MINOR** — совместимое дополнение правил или словаря.
- **PATCH** — исправление первичного нормативного текста без изменения требований.
- Предварительные версии имеют явный суффикс, например `0.1.0-draft.1`; это пример, а не опубликованный релиз.

Английский (`en`) — основной и нормативный язык. Опубликованный нормативный снимок должен иметь полный набор утверждённых английских записей. Русский (`ru`) — предпочтительный второй язык, но он и все остальные переводы опциональны. Переводы, метаданные и упаковка обновляются через `revision` без изменения нормативной версии. Опубликованные снимки неизменяемы.

До написания первого черновика зафиксируйте применимость источника и обоснование в [плане адаптации](../../../docs/it-ste-adaptation.ru.md). План не резервирует нормативные ID и не заменяет версионируемые записи.

Для первого черновика используйте [шаблоны](../../../templates/). Добавляйте только собственные материалы либо материалы с проверенными правами. Связь с ASD-STE100 должна объяснять, что адаптировано и зачем, а не создавать видимость официального одобрения ASD.
