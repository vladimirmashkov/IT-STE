# Версии IT-STE

[English](README.md)

Здесь создаются каталоги `<version>/revisions/<revision>/` по [общей структуре](../../../docs/storage.ru.md). Опубликованных версий и нормативных записей пока нет. По пути `0.1.0-draft.1/revisions/r0001/` созданы все [31 английское draft-правило](../../../docs/it-ste-canonical-pilot.ru.md). Генератор [единого черновика](../../../docs/IT-STE-draft.md) включает их и все 55 [словарных партий](../../../docs/it-ste-vocabulary.ru.md), 001–055. Для всех 2 196 исходных строк словаря есть черновые предложения: 90 `allowed`, 1 342 `restricted`, 401 `prohibited`, 146 `not-applicable` и 217 `needs-review`. Необработанных исходных строк нет, но 217 случаев значения или разметки остаются нерешёнными. Шесть первоначальных неоднозначных случаев первой партии разрешены после визуальной проверки физических страниц PDF 153–154; другие визуальные проверки не проводились.

Все словарные решения остаются `draft` / `editorial-review-needed`, а не утверждениями или каноническими записями терминов. Одобрение источника не переносится в IT-STE автоматически. Полное черновое покрытие исходных строк не означает полного утверждённого IT-словаря; для терминов, специфичных только для IT, ещё нужна отдельная инвентаризация. Утверждённого словаря и готовности к релизу или SFT нет, реестр релизов остаётся пустым.

Для `version` используется SemVer:

- **MAJOR** — несовместимое изменение нормативных требований или смысла разрешённых терминов.
- **MINOR** — совместимое дополнение правил или словаря.
- **PATCH** — исправление первичного нормативного текста без изменения требований.
- Предварительные версии имеют явный суффикс. `0.1.0-draft.1` сейчас обозначает черновой снимок, а не опубликованный релиз.

Английский (`en`) — основной и нормативный язык. Опубликованный нормативный снимок должен иметь полный набор утверждённых английских записей. Русский (`ru`) — предпочтительный второй язык, но он и все остальные переводы опциональны. Переводы, метаданные и упаковка обновляются через `revision` без изменения нормативной версии. Опубликованные снимки неизменяемы.

До написания первого черновика зафиксируйте применимость источника и обоснование в [плане адаптации](../../../docs/it-ste-adaptation.ru.md). Переносите рассмотренные стабильные целевые ID в соответствующие версионируемые draft-записи; концепции плана остаются отдельными и не заменяют эти записи.

Для текущего пилота следуйте его [закрытому контракту профиля](../../../docs/it-ste-canonical-pilot.ru.md), а не незаполненным общим [шаблонам](../../../templates/). Добавляйте только собственные материалы либо материалы с проверенными правами. Связь с ASD-STE100 должна объяснять, что адаптировано и зачем, а не создавать видимость официального одобрения ASD.
