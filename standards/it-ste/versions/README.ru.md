# Версии IT-STE

[English](README.md)

Здесь создаются каталоги `<version>/revisions/<revision>/` по [общей структуре](../../../docs/storage.ru.md). Опубликованных версий и нормативных записей пока нет. По пути `0.1.0-draft.1/revisions/r0001/` созданы все [31 английское draft-правило](../../../docs/it-ste-canonical-pilot.ru.md). Из них и первой словарной партии генерируется [единый черновик](../../../docs/IT-STE-draft.md). Из-за незавершённого словаря покрытие остаётся частичным, реестр релизов — пустым.

Для `version` используется SemVer:

- **MAJOR** — несовместимое изменение нормативных требований или смысла разрешённых терминов.
- **MINOR** — совместимое дополнение правил или словаря.
- **PATCH** — исправление первичного нормативного текста без изменения требований.
- Предварительные версии имеют явный суффикс. `0.1.0-draft.1` сейчас обозначает частичный draft-пилот, а не опубликованный релиз.

Английский (`en`) — основной и нормативный язык. Опубликованный нормативный снимок должен иметь полный набор утверждённых английских записей. Русский (`ru`) — предпочтительный второй язык, но он и все остальные переводы опциональны. Переводы, метаданные и упаковка обновляются через `revision` без изменения нормативной версии. Опубликованные снимки неизменяемы.

До написания первого черновика зафиксируйте применимость источника и обоснование в [плане адаптации](../../../docs/it-ste-adaptation.ru.md). Переносите рассмотренные стабильные целевые ID в соответствующие версионируемые draft-записи; концепции плана остаются отдельными и не заменяют эти записи.

Для текущего пилота следуйте его [закрытому контракту профиля](../../../docs/it-ste-canonical-pilot.ru.md), а не незаполненным общим [шаблонам](../../../templates/). Добавляйте только собственные материалы либо материалы с проверенными правами. Связь с ASD-STE100 должна объяснять, что адаптировано и зачем, а не создавать видимость официального одобрения ASD.
