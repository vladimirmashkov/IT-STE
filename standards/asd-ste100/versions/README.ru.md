# Версии ASD-STE100

[English](README.md)

Здесь создаются каталоги `<version>/revisions/<revision>/` по [общей структуре](../../../docs/storage.ru.md). Для Issue 9 есть черновая ревизия только с метаданными для [закрытого локального поиска](../../../docs/asd-ste100-local-reference.ru.md), но ни один снимок ASD-STE100 не зарегистрирован как опубликованный. Не используйте неявную «последнюю» редакцию.

- `version` сохраняет идентичность официальной редакции; точное издательское обозначение фиксируется также в метаданных источника.
- `revision` относится к нашему структурированному представлению, метаданным и переводам, а не к новой редакции ASD-STE100.
- Значение `primary_language` — `en`. Английский оригинал имеет приоритет; русский — предпочтительный опциональный язык перевода.
- `sources/` содержит сведения об источниках и правах, но не автоматически разрешённые к публикации PDF или текст стандарта.
- `content/` заполняется только после проверки прав на соответствующее содержимое и его использование. Без такой проверки остаёмся на уровне метаданных.
- Собственные ID записей не заменяют официальные номера правил: их сохраняют в `source_refs[].locator`.

Перевод ASD-STE100 хранится в пространстве `asd-ste100`. Изменённое для IT правило относится к `it-ste` и имеет собственный ID и обоснование адаптации. Ни одно из этих действий само по себе не разрешается лицензией нашего проекта в отношении чужого текста.
